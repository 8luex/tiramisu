PROJECT OVERVIEW
----------------
A lightweight, production-ready Personal Finance & Expense Tracker Discord Bot
optimized for Discloud free tier hosting (100MB RAM limit).

TECH STACK
----------
✅ Node.js v20+ with TypeScript (strict mode)
✅ discord.js v14 (minimal Gateway Intents)
✅ MySQL with Prisma ORM
✅ dayjs (timezone: Asia/Bangkok)
✅ Optimized for 100MB RAM deployment

CORE FEATURES
-------------
1. /record expense - Track expenses with 6 Thai categories
2. /record income  - Track income with 4 Thai categories
3. /summary        - Monthly/yearly financial summaries with charts
4. /compare        - Peer expense comparison (gamified)

DATABASE SCHEMA
---------------
Transaction Model:
- id: UUID (primary key)
- userId: Discord User ID (VARCHAR(20), indexed)
- type: ENUM (EXPENSE, INCOME)
- amount: DECIMAL(12,2)
- category: VARCHAR(50)
- note: VARCHAR(255) nullable
- createdAt: DATETIME (indexed)

Index: [userId, type, createdAt] for fast queries

COMMANDS REFERENCE
------------------
/record expense
  - amount (required): Number >= 0.01
  - category (required): 6 Thai expense categories
  - note (optional): Max 255 chars

/record income
  - amount (required): Number >= 0.01
  - category (required): 4 Thai income categories
  - note (optional): Max 255 chars

/summary
  - period (required): "เดือนนี้" or "ปีนี้"
  Returns: Income, Expense, Net Balance, Category breakdown with percentages

/compare
  - target (required): @User mention
  Returns: Monthly expense comparison with winner indicator

GETTING STARTED
---------------
1. Clone/download project
2. Run: npm install
3. Copy .env.example to .env and configure
4. Run: npm run prisma:push
5. Run: npm run dev (development)
6. Run: npm run build && npm start (production)

DEPLOYMENT TO DISCLOUD
-----------------------
1. Build: npm run build
2. Zip: dist/, node_modules/, prisma/, .env, discloud.config, package.json
3. Upload to Discloud dashboard
4. Start bot and monitor logs
